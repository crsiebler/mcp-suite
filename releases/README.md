# Historical release records

The existing v1.0.0 Markdown and JSON files are preserved records from the original
repository history. They may name removed servers, old paths and old publishing
procedures. They are not current setup instructions or proof of publication under
`@crsiebler`.

New release notes come from each server's `CHANGELOG.md`, generated from reviewed
Changesets and checked during version preparation. Do not add new duplicate JSON
or Markdown release payloads here. See [releasing](../docs/releasing.md).
