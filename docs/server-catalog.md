## Salesforce

Version: `1.0.3`. Repository entry: `servers/salesforce/dist/servers/salesforce/src/index.js`.

Optional/conditional variables: `SALESFORCE_INSTANCE_URL`, `SALESFORCE_ACCESS_TOKEN`, `SALESFORCE_API_VERSION`, `SALESFORCE_CLIENT_ID`, `SALESFORCE_CLIENT_SECRET`, `SALESFORCE_USERNAME`, `SALESFORCE_PASSWORD`, `SALESFORCE_GRANT_TYPE`, `SALESFORCE_LOGIN_URL`, `LOG_LEVEL`.
